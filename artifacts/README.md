# Generated artifacts

Store presentation images and videos here, separately from source data and application code. Each artifact should identify its generator and inputs. The replay media will arrive with the application change.

## Forecast benchmark

[`forecast-eval/report.html`](forecast-eval/report.html) is a standalone interactive report generated by `python3 -m app.forecast run`. [`forecast-eval/REPORT.md`](forecast-eval/REPORT.md) documents its inputs and limitations; `forecast-eval/dashboard.png` is a browser screenshot for review. Source joins and splits live in `data/manifests/forecast/`; generated metrics live in `data/processed/forecast/`.
